## 4. 食住行游购娱攻略

### 食
围绕中东烤肉、海鲜、甜点做选择。建议把用餐安排在住宿或景点附近，价格写区间，具体店铺营业状态发布前再核对。
### 住
第一次去优先考虑Downtown、Marina、Deira、Palm。主题是「第一次去」时，住宿最好靠近当天主片区，减少跨城通勤。
### 行
常用交通包括地铁、出租车、公交、机场线。先确认机场/车站到酒店的第一段，再按同方向片区安排每日行程。
### 游
核心游玩可从哈利法塔、迪拜喷泉、老城、沙漠中选择 2-3 个，再补一个街区散步或室内备用点。
### 购
购物和伴手礼可关注迪拜购物中心、黄金市场、香料市场、奥莱。购买前确认退税、保质期、尺寸和航空携带限制。
### 娱
晚间体验可从喷泉夜景、沙漠营地、游船、屋顶酒吧里挑选。夜间活动务必复核营业时间、预约规则和返程交通。

## 5. 3 天路线

- Day 1｜抵达与城市初印象：抵达酒店片区 -> 哈利法塔 -> 周边散步 -> 中东烤肉 -> 喷泉夜景
- Day 2｜第一次去主线日：迪拜喷泉 -> 海鲜 -> 老城 -> 迪拜购物中心 -> 沙漠营地
- Day 3｜轻购物与弹性收尾：慢早餐 -> 黄金市场或香料市场 -> 沙漠 -> 伴手礼补货 -> 游船

## 6. 避坑提醒

- 不直接照搬网上完整路线，先核对景点是否同方向、是否需要预约、是否当天开放。
- 热门餐厅和展览至少交叉查看官方页面、地图营业状态和近期评价。
- 交通信息以官方或运营方为准，末班车、机场线、节假日班次需要出发前再查。
- 购物前确认退税门槛、付款方式、保质期和行李限制。
- 热门区域可能人多，给拍照、排队、安检和休息留出缓冲。
