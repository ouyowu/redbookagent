## 4. 食住行遊購娛攻略

### 食
以 中东烤肉、海鲜、甜点 為優先，安排在住宿或景點附近最省時間。價格先寫區間，店家營業狀態發布前再核對。
### 住
第一次去可先看 Downtown、Marina、Deira、Palm。這次主題是「市场与烟火气」，住宿最好靠近當天主片區，減少跨城通勤。
### 行
常用交通包括 地铁、出租车、公交、机场线。先確認機場或車站到飯店的第一段，再按同方向片區排每日行程。
### 遊
核心玩法可從 哈利法塔、迪拜喷泉、老城、沙漠 裡選 2-3 個，再補 1 個街區散步或室內備用點。
### 購
購物與伴手禮可留意 迪拜购物中心、黄金市场、香料市场、奥莱。下單前確認退稅、保存期限、尺寸與航空攜帶限制。
### 娛
晚間體驗可從 喷泉夜景、沙漠营地、游船、屋顶酒吧 裡挑選。夜間活動務必再核對營業時間、預約規則與返程交通。

## 5. 3天路線

- Day 1｜抵達與城市初印象：抵達飯店片區 -> 哈利法塔 -> 周邊散步 -> 中东烤肉 -> 喷泉夜景
- Day 2｜市场与烟火气 主線日：迪拜喷泉 -> 海鲜 -> 老城 -> 迪拜购物中心 -> 沙漠营地
- Day 3｜輕購物與彈性收尾：慢早餐 -> 黄金市场 或 香料市场 -> 沙漠 -> 伴手禮補貨 -> 游船

## 6. 避坑提醒

- 不直接照搬網上完整路線，先核對景點是否同方向、是否需要預約、是否當天開放。
- 熱門餐廳與展覽至少交叉查看官方頁、地圖營業狀態與近期評價。
- 交通資訊以官方或營運方為準，末班車、機場線與假日班次需要出發前再查。
- 購物前確認退稅門檻、付款方式、保存期限與行李限制。
- 熱門區域人流可能很高，給拍照、排隊、安檢與休息留出緩衝。
