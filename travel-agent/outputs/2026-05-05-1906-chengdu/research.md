## 攻略要点

- 食：围绕 火锅、串串、盖碗茶 做选择。建议把用餐安排在住宿或景点附近，价格写区间，具体店铺营业状态发布前再核对。
- 住：第一次去优先考虑 春熙路、宽窄巷子、太古里、人民公园。主题是「周末两日轻旅行」时，住宿最好靠近当天主片区，减少跨城通勤。
- 行：常用交通包括 地铁、公交、高铁、机场线。先确认机场或车站到酒店的第一段，再按同方向片区安排每日行程。
- 游：核心游玩可从 武侯祠、杜甫草堂、熊猫基地、锦里 中选择 2-3 个，再补一个街区散步或室内备用点。
- 购：购物和伴手礼可关注 太古里、宽窄巷子、IFS、文殊院。购买前确认退税、保质期、尺寸和航空携带限制。
- 娱：晚间体验可从 茶馆、川剧、夜市、酒吧 里挑选。夜间活动务必复核营业时间、预约规则和返程交通。

## 3天路线提炼

- Day 1｜抵达与城市初印象：抵达酒店片区 -> 武侯祠 -> 周边散步 -> 火锅 -> 茶馆
- Day 2｜周末两日轻旅行主线日：杜甫草堂 -> 串串 -> 熊猫基地 -> 太古里 -> 川剧
- Day 3｜轻购物与弹性收尾：慢早餐 -> 宽窄巷子或IFS -> 锦里 -> 伴手礼补货 -> 夜市
