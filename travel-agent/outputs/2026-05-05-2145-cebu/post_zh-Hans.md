## 4. 食住行游购娱攻略

### 食
围绕 烤乳猪、海鲜、芒果甜品 做选择。建议把用餐安排在住宿或景点附近，价格写区间，具体店铺营业状态发布前再核对。
### 住
第一次去优先考虑 宿务市、麦克坦、海边度假区、码头。主题是「古城古镇游」时，住宿最好靠近当天主片区，减少跨城通勤。
### 行
常用交通包括 Grab、船运、包车、机场车。先确认机场或车站到酒店的第一段，再按同方向片区安排每日行程。
### 游
核心游玩可从 麦哲伦十字架、圣婴教堂、墨宝、薄荷联游 中选择 2-3 个，再补一个街区散步或室内备用点。
### 购
购物和伴手礼可关注 SM Seaside、Ayala、市场、伴手礼店。购买前确认退税、保质期、尺寸和航空携带限制。
### 娱
晚间体验可从 海岛跳岛、潜水、夜市、酒吧 里挑选。夜间活动务必复核营业时间、预约规则和返程交通。

- Day 1｜抵达与城市初印象：抵达酒店片区 -> 麦哲伦十字架 -> 周边散步 -> 烤乳猪 -> 海岛跳岛
- Day 2｜古城古镇游主线日：圣婴教堂 -> 海鲜 -> 墨宝 -> SM Seaside -> 潜水
- Day 3｜轻购物与弹性收尾：慢早餐 -> Ayala或市场 -> 薄荷联游 -> 伴手礼补货 -> 夜市

## 6. 避坑提醒

- 不直接照搬网上完整路线，先核对景点是否同方向、是否需要预约、是否当天开放。
- 热门餐厅和展览至少交叉查看官方页面、地图营业状态和近期评价。
- 交通信息以官方或运营方为准，末班车、机场线、节假日班次需要出发前再查。
- 购物前确认退税门槛、付款方式、保质期和行李限制。
- 热门区域可能人多，给拍照、排队、安检和休息留出缓冲。
